Dataset

This project uses the NASA C-MAPSS Turbofan Engine Degradation Dataset (FD001) for aircraft engine Remaining Useful Life (RUL) prediction.

The raw dataset is not included in this repository.

Dataset Source

NASA Prognostics Data Repository – C-MAPSS Turbofan Engine Dataset

Download the dataset and place the FD001 training file in the appropriate data directory before running the EDA notebook.
